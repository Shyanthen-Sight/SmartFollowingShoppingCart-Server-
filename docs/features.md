# 功能清单

## Web 管理端（管理员）

- 车辆管理：车辆建档、生成手环盒绑定二维码
- 实时监控：车辆在线状态、位置与状态大屏
- 绑定管理：查看用户绑定关系、异常解绑
- 告警处理：车辆离线、低电量、目标丢失
- 数据复盘：全量轨迹回放、使用统计看板

## 小程序用户端（用户）

- 扫码绑定：扫手环盒二维码，绑定成功提示开盒取手环
- 跟随控制：启动 / 暂停跟随
- 远程干预：急停、一键召回
- 行程复盘：本次轨迹回放、事件时间线、电量曲线
- 我的：行程记录、解绑手环

## 后端

- 登录鉴权（管理员 + 微信用户）
- 绑定关系管理
- 指令转发与审计（前端不直发）
- 轨迹 / 事件 / 状态落库
- 告警规则与推送

## 页面开发顺序（先假数据，后接 MQTT）

1. 小程序控制页（核心，演示最出镜）→ 首页 → 复盘页 → 我的
2. Web 登录 → 车辆管理 → 监控大屏 → 告警与复盘
